Weather+

Select the weather provider and units sent to apps and watchfaces. Settings apply to all weather locations.

US ZIP codes or city names, using the same lookup as Timeline WX.

Forecasts are cached for 15 minutes and updated when an app requests weather. No background polling.

Set 0 to disable a provider; 1 is first choice, 2 second, and so on. Each enabled provider must have a unique number. If a source fails or is unavailable for the location, Weather+ tries the next.
Requires an active One Call 3.0 subscription. Stored locally by the plugin.

Permissions: For every forecast provider, alert provider, and additional data source you enable, make sure its corresponding approval is also checked in Pebble’s plugin permissions. Disabling a source here does not grant or revoke its permission.

Availability, forecast length and variables depend on model and location.
Auto uses NWS in the US, public MeteoAlarm feeds in supported European countries, and OpenWeather elsewhere when an API key is configured. MeteoAlarm warnings are counted only when their geographic area matches your location. Coverage varies by region. An unavailable alert service is not the same as zero active alerts; diagnostics show the selected and actual source, status, and errors. Enable the corresponding domain approval in Pebble permissions.
